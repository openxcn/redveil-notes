身份 NFT 四层：持有即生效，转走即失效

个人整理，非官方公告，不构成投资建议；文中数字以官方文档与链上快照为准。

红魔的身份不是注册出来的，是"持有"出来的。钱包里有那张 NFT，身份就自动生效；NFT 转到别的地址，身份跟着一起走，原地址立刻失去它。这条规则决定了：在这个体系里谈身份，永远得回到钱包，而不是账号。

持有即生效，不需要绑定

按游戏内第 07 节文档：钱包持有红魔 NFT 时，身份自动以所持编号生效，无需绑定；全站邀请关系、推广与分润挂账都以该编号为准；NFT 转到别的地址后，身份一起转走。

这里没有"申请—审核—开通"的流程，也没有后台可以给你改级别。链上持有什么，就是什么。

四层身份，按权限分

游戏内文档把参与者分成四层：

  • 普通玩家：可以买马、托管、报名、下注、逛市场。没有红魔 NFT 也能参与生态。
  • 社员：持有红魔 NFT，享受社员身份与推广分润资格。
  • 社长：可以开养马场、开赛事、给自己的公马挂牌配种。
  • 基金会社长：最高层级，参与平台分润的 FS 档。

要说明的是：这四层之间升级的具体条件、名额与费用，事实库没有收录，本文一律写"待核实"，不给数字。任何声称知道确切门槛的说法，都应该以官方文档或链上参数为准。

没有 NFT 怎么进：绑定一位邀请人

没有红魔 NFT 也能参与，但必须先绑定一位邀请人的红魔 NFT 编号。绑定之后才能下注、参赛、买卖、繁殖；未绑定只有投人气票一个入口，且不参与任何分润。

这条绑定终身沿用、不能更换。之后如果你自己持有了红魔 NFT，身份会自动改为以你自己的编号生效。换句话说：绑定是入场券，持有才是身份。

推广编号只在场地页 ?ref 记归属

持有 NFT 后，"我的 → 推广"会显示你的推广编号，也就是你的红魔 NFT 编号。分享社长场地页时，在链接后加 ?ref=编号，场地页才会识别归属。

关键限制：只有场地页（#venue/社长地址）认这个参数，普通首页链接的 ?ref 目前不记录归属。把 ?ref 加在首页上，看起来一样，实际上不产生归属记录。这是很多人推广白做的主要原因。

身份可转让，代价也是真的

身份跟着 NFT 走，意味着它可以被卖、被转。接手的人获得同样的身份与挂账归属，转出的人一并失去。这里没有"账号保留、等级不变"这种选项。

所以转出之前值得问自己一句：我卖的是这张 NFT 的价格，还是我在这个体系里的位置？按这套规则，两者是同一个东西。

三个别误读的点

  1. "持有即生效"意味着不用绑定，也意味着一旦转走就没有缓冲。
  2. 绑定邀请人编号是终身的、不能更换，绑定前要想清楚。
  3. ?ref 只在场地页生效，首页链接不记归属。

规则在游戏内第 07 节"身份与分润"有原文，可以逐条核对。
